# 小账本

一个给自己用的记账 App。本地网页应用，打开就能用，数据只存在你自己的设备上。

## 在 iPhone 上使用

先说一件最重要的事：**数据存在浏览器里，并且绑定在「你访问的那个网址」上。**

`http://192.168.31.225:8787` 和 `https://xxx.pages.dev` 在你手机上算两个完全不同的
账本。所以请**先决定以后长期用哪个地址，再开始记第一笔账**。之后想换地址，只能靠
先在旧地址导出备份、在新地址导入。

还有一点要预期清楚：**手机和电脑之间不会自动同步**。哪怕打开的是同一个网址，两台设备
各自存各自的，互不影响。想两边都有，只能在一台设备上导出、到另一台导入。

下面三种方式，选一个。

### 方式 A：放到网上（推荐，一次配置长期用）

把文件夹传到免费的静态托管上，拿到一个 HTTPS 地址。好处是随时随地都能打开、
电脑不用开机、而且能离线使用（浏览器规定只有 HTTPS 才允许离线缓存）。

不需要会写代码，也不需要买服务器或域名。两种做法：

- **不用 git，最省事**：打开 Netlify 或 Cloudflare Pages 的网页，选择「直接上传
  文件夹 / 拖拽部署」，把整个 `sdlv2` 文件夹拖进去，几秒后就会得到一个 HTTPS 网址。
- **会用 git**：推到 GitHub 仓库，在仓库设置里打开 Pages；或者用 Vercel 导入这个仓库。

免费方案里 GitHub Pages 需要仓库公开，这没关系 —— 公开的只是代码，你的账目数据
存在手机浏览器里，从来不会进仓库、也不会被上传。介意的话用 Cloudflare Pages 或
Vercel，免费版支持私有仓库。

拿到网址后，看下面的「添加到主屏幕」。

### 方式 B：局域网（今天就能用，不用注册任何账号）

1. 电脑上双击 `start.sh`（或在终端里跑 `./start.sh`）。
2. 手机连上和电脑同一个 Wi-Fi。
3. 手机 Safari 打开终端里显示的「手机（推荐）」地址，形如 `http://你的电脑名.local:8787`。

几个要注意的地方：

- **电脑必须开着**，这个窗口关掉 App 就打不开了。
- 优先用 `.local` 那个地址，不要用 `192.168.x.x`。IP 会被路由器换掉，`.local` 名字不会变，
  而地址一变就等于换了一个空账本。
- 局域网是 http 不是 https，所以**不能离线**，也没法用方式 A 那种离线缓存。
- 电脑名可以在「系统设置 → 通用 → 共享 → 本地主机名」里看到和修改。

### 方式 C：做成真正的原生 App

需要 Mac 上的 Xcode 和 Apple ID。免费账号可以侧载到自己手机上，但**每 7 天要重新装一次**；
免掉这个麻烦需要 99 美元/年的开发者账号。除非你想上架，否则不值得。

### 方式 D：自己的群晖 NAS

如果你的 NAS 常年开机、而且支持 Docker（x86 机型，比如 DS220+），可以把它当成自己的
托管服务器，拿到一个固定不变的 HTTPS 地址，完全不依赖第三方，也不用公网 IP、不用备案。

完整步骤见 [docs/nas-deploy.md](docs/nas-deploy.md)。

注意：ARM 机型（比如 DS220j）装不了 Docker，这条路会窄很多，用方式 A 更省事。

### 添加到主屏幕（任何方式都需要这一步）

必须用 **Safari**，iOS 上的 Chrome 不支持把网页装成 App。

1. Safari 打开你的账本网址
2. 点底部中间的「共享」按钮
3. 往下滑，选「添加到主屏幕」
4. 确认名字是「小账本」，点「添加」

之后从桌面图标打开，就是全屏、没有地址栏的样子，和装了一个 App 没区别。

图标已经准备好了（`icon-180.png` 等）。想换图标就改 `tools/make-icons.py` 里的
`BG_TOP` / `BG_BOTTOM` / `BARS`，然后跑 `python3 tools/make-icons.py`。

### 换手机、换浏览器、换网址之前

先去「我的」页面点「导出备份（JSON）」，把文件存到 iCloud 或网盘。新设备上打开账本，
点「导入备份」把内容贴进去即可，导入是追加式的，不会覆盖已有记录。

Safari 清除网站数据、iOS 长期不用自动回收存储，都可能把账本一起清掉，所以建议
每个月导出一次。

## 五个页面

**记账**：选支出/收入 → 点分类 → 敲金额 → 点完成。日期和备注在数字键盘右侧，默认今天、可不填。
电脑上直接用键盘敲数字，回车保存，退格删除，Esc 清空。

**明细**：按月看流水，顶部有本月支出/收入/结余，可以按全部/支出/收入筛选。
点任意一条可以改金额、日期、分类、备注，或者删除。

**图表**：本月支出按分类排行（带占比），以及近 6 个月支出趋势。
最上面是**年度总支出**——把手记的流水和固定成本加起来，这才是"我一年花多少"的答案。

**家底**：每月必须交的钱，和欠的钱。
- **贷款**：录一次余额、利率、月供、到期日，之后每次还款只更新余额。它会自动把月供拆成
  利息和本金，并且**检查按现在的月供能不能在到期前还完**——还不完会直接告诉你届时还差多少。
- **固定费用**：物业费、取暖费、保险这类，按月或按年，录一次自动计入。

  这一块的意义：这些钱不经过每天记账，但往往是你支出里最大的一块。不录进来，
  年度支出会被严重低估。

**我的**：累计数据总览，以及导出/导入/清空。

## 关于数据

数据保存在浏览器的 localStorage 里，不会上传到任何地方，页面也没有任何联网请求。

CSV 是给 Excel / 数字表格用的，只能导出不能导入，备份请用 JSON。

导入是追加式的，会自动跳过 id 重复的记录，所以同一份备份重复导入不会产生重复数据。
贷款和固定费用按**名称**匹配：已存在的更新余额、不存在的才添加。所以你以后只要改一下
余额数字、重新导入同一份文件，就能更新家底。

导入可以直接选文件（「我的 → 导入备份 → 选择备份文件」），不用手动粘贴 JSON。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构 |
| `styles.css` | 样式 |
| `app.js` | 全部逻辑：记账、明细、图表、导入导出 |
| `start.sh` | 局域网启动脚本 |
| `manifest.webmanifest` | PWA 配置（名字、图标、独立窗口运行） |
| `sw.js` | 离线缓存，只在 HTTPS 下生效 |
| `icon-180.png` 等 | App 图标，由 `tools/make-icons.py` 生成 |
| `tools/cost-model.py` | 电脑上的家底模型：净资产、生存月数、负债率、还款结构自检 |
| `tools/inspect-legacy.py` | 体检从旧记账网站导出的 .xls |
| `tools/export-big-expenses.py` | 从旧账本挑出需要人工甄别的大额支出 |

### 关于隐私

**`out/` 目录不会进 git**（见 `.gitignore`），所以那里面的真实金额只留在你本机。

`tools/cost-model.py` 本身不含任何真实数字，它从 `out/我的数据.json` 读取；文件不存在时
用一份示例数字跑，让你能看到输出长什么样。想改余额，改那个 JSON 就行，不用动代码。

没有依赖、没有构建步骤、没有后端，改完文件刷新浏览器就生效。

两个和缓存有关的坑，改代码时会碰到：

- **用 `start.sh` 在电脑上看**：普通刷新就够。
- **部署到网上之后**：`sw.js` 会先用缓存让你秒开、再在后台更新，所以改动要**打开两次**
  才看得到。急的话清一下该站点的缓存。

想先看看用久了是什么样子，在网址后面加 `?demo=1`，会加载一批示例数据，且不会写入真实账本。

## 后续可以加的东西

- 自定义分类（比如单独记「房租」「孩子」）
- 预算提醒：给某个分类设月度上限，超了在图表页标红
- 固定支出自动记账：房租、订阅这类每月一样的，一键复制上月
- 多账户 / 付款方式（现金、微信、支付宝、信用卡）
- 待办式的「重复记账」和记账打卡
- 存到本地数据库（SQLite）而不是浏览器，方便以后做桌面端或和其它工具打通

`.env` 是之前另一个 Flask 项目留下的配置文件，和这个 App 无关。
